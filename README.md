# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 出版基线流程（《潮汐线》冻结稿）

1. **差异处置草稿**：版本页选择基线/目标版本（默认 v11 → v12），逐条比较音符、力度、延音线与换页提示；摘要不改总谱。
2. **逐条结论**。接受才并入总谱；拒绝保留原值并在条目与评论上标清。挂接到差异的评论随结论闭环（已采纳 / 已拒绝），无挂接评论可手动记录结论。
3. **锁定出版基线**：全部差异有结论且待处理评论为零才可锁定；锁定时按结论合并总谱，并冻结当时的四册分谱设置。
4. **锁定之后**：总谱只读，四册分谱按基线快照生成；后续编辑须开启新草稿，旧基线在“基线与历史”中可查回。
