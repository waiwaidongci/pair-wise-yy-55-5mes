# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 技术栈

React、Ant Design、Redux Toolkit、React Router、RTK Query、VexFlow、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62055

```bash
npm run build
```

## 冻结稿差异处置与出版基线

- v11/v12 均保存全量声部快照与分谱设置（换页位置、提示音小节、提示音显隐），差异由 `src/diff.ts` 逐音符计算：音高、时值、力度、延音线、换页提示。
- “版本与评论 → 版本差异”逐条**接受**（补丁并入总谱）或**拒绝**（保留 v11 原值并标清），支持全部接受/拒绝；评论“应用并并入总谱”会把关联差异真正写入总谱并了结评论。
- **锁定出版基线**的前提：所有差异均有结论且待处理评论为零。锁定后按当时设置生成四册分谱快照，总谱差异处置单清空、从新草稿继续编辑；旧基线在“出版基线”页签可随时查回（只读），分谱页切换查阅基线或当前草稿。
